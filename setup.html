ROUTE 01 - FIRE TV

Set up a Fire TV device

  1. Open the Amazon Appstore and search for the player recommended for your trial.
  2. Install the player, then choose the login method named in your LoopMint setup message.
  3. Enter the supplied server address, username, and password carefully.
  4. Allow the first playlist and programme-guide refresh to finish.
  5. Confirm picture, sound, and remote navigation across a few categories.
Player missing?

Send support the Fire TV model and country before installing an alternative.

ROUTE 02 - ANDROID AND GOOGLE TV

Set up an Android device

  1. Open Google Play on the television, box, phone, or tablet.
  2. Install the compatible player listed in your LoopMint message.
  3. Select the supplied login type and enter the details exactly as provided.
  4. Wait for categories and programme information to finish loading.
  5. Test playback, subtitles, favourites, and full-screen controls.
Keep it official

Use the app-store version when available. Close background apps on low-spec boxes before testing higher-resolution playback.

ROUTE 03 - WINDOWS

Set up a Windows computer

  1. Confirm whether the computer uses Windows 10 or Windows 11.
  2. Install the recommended player from its official website or Microsoft Store listing.
  3. Choose the matching playlist or account login option.
  4. Enter the private trial details and allow the guide to synchronise.
  5. Confirm audio output, full-screen playback, and keyboard controls.
Protect your login

Keep the player updated and never share screenshots that expose usernames, passwords, or server addresses.

ROUTE 04 - SMART TV

Set up a compatible Smart TV

  1. Write down the television brand, model, and operating system if shown.
  2. Open the official television app store and search for the recommended player.
  3. Note whether the player requests account details, a playlist, or a device identifier.
  4. Follow the matching route in your LoopMint setup message.
  5. Refresh the guide, test the remote, and add a few favourites.
No suitable app?

A supported Fire TV, Android, or Apple TV device can provide a clearer route through HDMI.

ROUTE 05 - APPLE DEVICES

Set up Apple TV, iPhone, iPad, or Mac

  1. Open the App Store on the device you will use for viewing.
  2. Install the compatible player recommended for that Apple platform.
  3. Choose the account or playlist login type supplied by LoopMint.
  4. Enter the details and wait for the first synchronisation to complete.
  5. Test AirPlay, subtitles, audio selection, and favourites where supported.
Check the exact platform

Availability changes between Apple devices and regions. Confirm the device before purchasing a separate player licence.

ROUTE 06 - MAG AND FORMULER

Set up a compatible television box

  1. Send support the full model name and current software version.
  2. Confirm whether the device uses a portal, playlist, or account login.
  3. Open the built-in or recommended player and locate account settings.
  4. Enter only the server details supplied for your own trial or plan.
  5. Restart the player, allow the guide to load, and test the remote.
Use model-specific steps

Menus vary between box generations, so follow the exact route supplied for your receiver.
